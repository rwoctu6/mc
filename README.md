## 年付7折之外，还有哪些折扣能叠上去

这部分是“雨云年付优惠”真正的省钱空间。7折只是官方那层，下面这些是能继续往下压的：

- **新用户首月5折券**：通过优惠链接注册并绑定微信后，账号里通常会到账一张新用户券，多数测评文章写的是首月5折。券种和适用范围按你实际收到的算，注册后去“积分中心 → 我的优惠券”看一眼就知道有没有、能不能用于年付订单。
- **积分商城换的8折新购券**：用积分兑换，可作为新购券使用，能和年付7折叠加。8折 × 7折 = 5.6折，这是论坛和测评里出现频率最高的组合。
- **代理/上级发的65折新购券**：折扣力度比8折券更大，但只能由你的邀请关系对应的上级赠送，自己没法选。社区里常见的做法是注册时走一个明确会发65折券的邀请渠道。
- **消费返利**：第三方整理的说法是消费满 1 元后返利比例从 10% 提到 12%，满 800 元能到 20%，返利可提现。具体比例以后台 VIP 页面显示为准。
- **淘宝店充值卡的积分返**：雨云在淘宝的企业店里卖充值卡，最低 20 元一档，下单后按要求写评价可返 10000~20000 积分；积分兑换汇率是 2000 积分 = 1 元。这件事论坛里讨论得很多，注意它是按单返、需要发工单，且返多少和评论质量有关。

把这几层乘起来是什么效果，社区里有人算过一笔账：

> 0.65（65折券）× 0.88（消费返利）× 0.8（淘宝充值折扣）× 0.7（年付7折）≈ 0.32

也就是说，理论最低能压到三折出头。但这个数字的前提比较苛刻：你得先找到一个愿意发65折券的上级，再买一次 1 元的试用把返利等级提上去，然后通过淘宝买充值卡、写评价、发工单换积分。任何一环不做，实际折扣就往上走。

关于试用，这里有个细节值得注意：**1 元试用一天之后，再购买同样的机型依然算新购**，而不是续费。所以想用新购券的话，先试一天再买一年，顺序别反。雨云支持云服务器和游戏云 1 元试用一天（每款限一次，较贵机型试用价会高一点），也支持 7 天无理由退款，但每个账号只有 3 次机会。

## 年付前，这几件事先确认

- **续费折扣低于新购**。社区讨论里对续费能拿到多少说法并不一致，有说最大 85 折的，也有说只能 8 折的，但方向是明确的：新购优惠大于续费。如果打算长期用，第一年一次付一年更划算。
- **独立 IP 是额外成本**。普通 IP 5 元/个/月，高防 IP 30 元/月起，湖北十堰等机房必须购买独立 IP（约 50 元/月）。年付算总价时把这块加上，别只看机器价。
- **流量型和带宽型二选一**。做站、跑接口选小带宽不限流量更稳；下载站、大流量图床这类突发业务，限流量大带宽更合适。
- **部分机房是 NAT 机**。江苏宿迁的 NAT 机型共用公网 IP、可开端口映射，适合内网穿透和折腾，不适合直接对外建站，除非加购独立 IP。
- **升级和迁移比较灵活**。购买后可以按天补差价升级套餐、扩容云盘、加购独享 IP、迁移地区。这点让年付的试错成本比想象中低——先用入门配置付一年，不够了再补差价升级，比一开始就买高配被套住更合理。
- **游戏云选单核强的**。浙江宁波的 EPYC 7A23、江苏宿迁和镇江的 7950X / 14900K 系列是面向 MC 开服这类高单核负载的机型，年付价普遍在几百到一千多元区间，和普通云服务器不是同一套定价逻辑。

## 什么情况值得年付，什么情况别急

值得直接上一年：

- 已经有一台同线路机器跑了几个月、性能心里有数；
- 建站、博客、图床、API 这类长期在线业务，停机成本高；
- 开 MC 服、幻兽帕鲁这类游戏服，预计会开半年以上；
- 跨境业务，需要固定线路和固定 IP。

建议先月付或季付：

- 第一次用雨云，不确定线路在自己当地运营商下的实际表现；
- 只是短期测试项目、临时压测、跑一次性的数据任务；
- 预算紧，年付会占掉现金流——季付9折省得少，但压的钱也少。

顺便说一句，年付并不等于“锁死”。7 天无理由退款的前提取决于你买多久、有没有超出规则，退款次数也有限；而升级、扩容、迁移这些操作本身是按天补差价，不会因为付了年付就没法动。

## 常见问题

**年付折扣和优惠券能同时用吗？**
可以。年付7折是官方按付费周期给的折扣，优惠券是另一套机制，两者在结算页会一起计算。能不能叠到同一张订单上，取决于券面标注的适用范围。

**首月5折券和年付7折哪个先用？**
首月5折券针对的是单月周期，通常用在“先试一个月”这一步。如果确定要年付，用新购券叠年付7折的实际总价更低。

**年付之后中途不用了能退吗？**
雨云支持 7 天无理由退款，每个账号限 3 次。超过这个窗口的退款按具体规则走，下单前建议先看清产品页的退款说明。

**续费还能享受7折吗？**
年付续费同样可以选一年周期，但优惠券方面，新购券通常不能用于续费。续费的折扣力度普遍低于新购，这也是很多人第一年一次性买长的原因。

**为什么同一机房价格不一样？**
雨云的机房按线路和 CPU 平台分成多个区，比如香港同时有移动优化、三网直连、国际大带宽几条线，硬件也有 EPYC 7K62、7A23、Intel 14900K 等不同平台，价格自然分层。选之前先想清楚用途是建站、跨境还是开游戏服。
